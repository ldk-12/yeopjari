# 의존성 및 고지

40개 JAR 모두 설치된 Gradle 캐시의 원본 JAR 또는 AAR 안의 classes.jar와 SHA-256이 일치한다. dependencies-lock.json에 Maven 좌표, 원본 파일 해시와 추출 JAR 해시를 기록했다.

37개는 Apache-2.0 선언 또는 공식 소스 헤더 근거가 있다. 나머지는 Vehicle 2.3.2, vehicle-aidl 1.1.1, vehicle-data 1.1.11이다. evidence/에는 공식 POM, 원문 SDK 약관과 출처 기록을 보존했다. Apache-2.0 전문과 NOTICE를 함께 제공한다.

archive-notice-scan.json은 실제 원본 JAR/AAR의 LICENSE/NOTICE/COPYRIGHT 이름 항목 검사다. 항목이 없다는 사실은 별도 고지가 불필요하다는 의미가 아니다. 포함된 제3자 코드와 SDK 앱 배포 조건의 최종 확인은 남아 있다. SDK 원본·키는 포함하지 않는다.
